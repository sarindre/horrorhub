# Design source files

- `pumpboy-original.png`: PumpBoy, the HorrorHub mascot, drawn by **totalnightmare**, who is happy for him to be used here. The artwork is hers; the project's code license doesn't cover it.

`node scripts/make-icons.mjs` builds the app icons (`public/icons/`, `build/icon.png`, `src/assets/pumpboy.png`) from this file. When a larger or "HorrorHub"-lettered version arrives, replace the file and run the script again.
